# AR_Shared_Space(多機共享空間技術研究)

> 讓多台 iOS 裝置能在同一個實體空間中，看見彼此對齊、位置一致的 AR 內容。
> 一個由我獨立研究、設計並實作的 AR 共享空間技術驗證專案。

**開發模式**：個人獨立研究與技術驗證（公司內部技術預研專案）
**平台／技術**：iOS、ARKit（ARWorldMap）
**專案性質**：技術可行性研究，非最終產品

> 本專案之原始展示影片涉及公司內部技術資產，不便公開，故本文件僅以文字說明研究內容、技術原理與我個人的實作貢獻，不附上影片或程式碼。

## 專案簡介

在多人 AR 應用（如多人 AR 遊戲、協作標註、共享導覽等）中，「讓不同裝置在同一個實體空間中看到位置一致的虛擬內容」是核心挑戰之一。這個專案是我在公司獨立研究 AR 共享空間可行性時所做的技術驗證，目標是搭配 iOS 平台的 ARKit 技術，測試並實作出「多台裝置可基於同一個實體空間座標系統，穩定顯示位置一致之 AR 內容」的基礎方案，作為後續多人 AR 專案的技術基礎。

整個研究由我獨立完成，涵蓋技術選型、原理研究、原型開發、實機測試與問題排查，沒有既有內部框架可直接套用，需從 ARKit 官方文件與底層 API 開始逐步摸索與驗證。

## 研究內容與實作重點

### 技術研究與方案設計
- 研究 ARKit 提供的空間定位與環境理解機制（平面偵測 ARPlane、特徵點雲追蹤、環境掃描狀態回饋等），評估其作為多機共享空間基礎的可行性
- 深入研究 **ARWorldMap** API：了解其如何將裝置掃描過的環境特徵點、平面資訊與錨點（Anchor）序列化為可儲存、可傳輸的資料，作為實現「不同裝置載入同一空間地圖」的核心技術方案

### 程式設計與互動機制實作
- **環境掃描與地圖建立流程**：實作即時環境掃描機制，透過畫面上的視覺化回饋（掃描中／已建圖／地圖擴展中等狀態文字提示）引導使用者掃描足夠的環境特徵，確保地圖建立品質
- **ARWorldMap 序列化與儲存**：實作將掃描完成的空間地圖序列化為位元資料並寫入裝置儲存空間的功能，供其他裝置或後續使用讀取
- **地圖載入與重定位**：實作讀取已儲存地圖資料、反序列化並套用至當前 AR Session 的流程，讓裝置能基於過去掃描的環境重新定位自身在空間中的位置與朝向
- **錨點管理系統**：實作場景中虛擬物件與空間錨點的綁定、新增／更新／移除的追蹤管理機制，確保虛擬內容能穩定附著於實體空間中的正確位置
- **除錯與狀態視覺化工具**：自行開發一套即時除錯介面，將 Mapping Status（未建圖／已建圖／擴展中）、可信賴的映射區域與追蹤誤差區域等內部狀態即時視覺化呈現於畫面上，大幅加速開發過程中的問題排查效率

### 視覺化除錯特效整合
- 特徵點雲即時視覺化：以動態光點呈現裝置當下偵測到的環境特徵點分布，協助判斷掃描品質
- 空間範圍視覺化：以線框繪製出目前地圖涵蓋的空間邊界，讓使用者清楚掌握可用的 AR 互動範圍
- 狀態文字與色彩系統設計：以顏色（綠／黃／紅）區分不同追蹤與映射狀態，讓開發與測試過程中能快速判讀當前系統狀態

## 技術亮點

- **從零開始的獨立技術研究**：非既有框架的套用，而是從 ARKit 底層 API 原理開始研究、實驗、除錯，最終產出可驗證的技術方案
- **空間地圖的序列化與重定位機制**：完整實作 ARWorldMap 資料的儲存、讀取與重新定位流程，是實現「多機共享同一 AR 空間」的關鍵基礎技術
- **開發用即時除錯視覺化工具**：自行設計並實作一套視覺化除錯系統，不僅用於此專案，也可作為往後其他 AR 專案開發時的通用除錯輔助工具
- **扎實的問題排查與實機驗證經驗**：AR 空間定位技術在不同光線、環境紋理條件下表現差異大，過程中需大量實機測試、記錄追蹤狀態並排查定位失準、地圖遺失等問題

## 應用價值

此技術研究成果可作為以下應用的基礎：
- 多人 AR 遊戲（多裝置需在同一空間看到位置一致的虛擬角色或物件）
- 協作型 AR 應用（如多人共同標註、共同編輯同一虛擬場景）
- 展場／導覽型 AR 應用中，多位訪客共享同一組 AR 內容的體驗設計
